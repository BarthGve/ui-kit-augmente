# Timeline

`Timeline` shows events as an ordered list: each event has a date, a title and
optional content, and may carry a state. It is presentational: no state, no
data fetching.

```tsx
import { Timeline } from "@gouvfr-lasuite/ui-components";

<Timeline
  aria-label="Order history"
  events={[
    { id: "received", date: "2026-10-12", title: "Order received", state: "done" },
    { id: "packed", date: "2026-10-13", title: "Packed", state: "current" },
    { id: "shipped", date: "2026-10-15", title: "Shipped", state: "upcoming" },
  ]}
/>;
```

<Canvas of={TimelineStories.Default} />

The root is an `<ol role="list">` (the role keeps list semantics that
`list-style: none` removes in Safari / VoiceOver): assistive technologies
announce an ordered list of N items. Name it with `aria-label` or
`aria-labelledby`. `className` and other attributes go to the `<ol>`.

**Order is the caller's.** Events are rendered in the order of `events`, never
sorted by date: an intentional order (newest first, grouped steps) is kept.
An empty `events` renders an empty list; show an empty state around it if
needed.

## States

`state` is `done`, `current` or `upcoming`. A state is never shown by colour
alone: each has its own marker shape (a check on a filled disc, a dot inside
a ring, an empty ring) and a visually hidden label read after the title
("Done", "Current", "Upcoming", from the locales). The current event carries
`aria-current="step"`. Without `state`, the marker is a neutral ring and no
label is read. Markers are decorative (`aria-hidden`).

## Content

`title` and `content` accept any React node. Long text wraps.

## Dates and time zone

`date` is a `Date` or an ISO string, rendered in a `<time dateTime>` and
formatted with `Intl.DateTimeFormat` in the provider's locale, by default
`{ dateStyle: "medium" }`; `dateFormat` replaces those options.

A date-only string (`"2026-10-13"`) is a calendar day: it is formatted in UTC,
so it shows the same day in every time zone. A `Date` or a string with a time
is formatted in the user's time zone. A string that is not a date is shown as
given.

## Orientation

`orientation` accepts `"vertical"` (default) and `"horizontal"`.

Horizontal lays the events on one row that never wraps: each event is at
least `item-min-width` wide, markers sit on top and the connector runs from
one marker to the next. The list is wrapped in a scroll region
(`role="region"`, `tabindex="0"`) that scrolls sideways when the row is wider
than its container, so the page itself never scrolls. Keyboard users focus
the region with `Tab` and scroll it with the arrow keys; it shows a focus
ring drawn inside its box. The region takes its name from `aria-label`, or
the localized "Timeline" when none is given. Vertical renders no region.
