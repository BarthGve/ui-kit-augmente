AlertModal — reference mockup v2 (s26)

Inspired by the owner's reference: title, muted message, divider, actions right-aligned (dismiss then primary). Without a severity there is no icon (neutral, as the reference); with a severity an icon precedes the title and the primary button takes the semantic colour. The primary button holds the initial focus (ring shown). Bottom-right case: dismiss only.
